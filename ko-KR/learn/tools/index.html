언어 서버

언어 서버는 구문 강조와 코드 자동 완성 등의 다양한 기능을 제공하는 편집기 독립적인 도구입니다. 보다 풍부한 개발 경험을 위해서는 구문 강조를 위한 확장 프로그램 대신 언어 서버를 사용해보세요.

  • zigtools/zls
